# 🔒 Security Automation Scripts

⚠️ **DISCLAIMER**: These tools are for **educational purposes and authorized testing only**. Unauthorized scanning is illegal. Use only on systems you own or have explicit permission to test.

## 📚 Tools

| Tool | Description | File |
|------|-------------|------|
| **Port Scanner** | Lightweight TCP port scanner with banner grabbing | `port_scanner.py` |
| **Log Analyzer** | Detects suspicious SSH brute-force attempts | `log_analyzer.py` |
| **File Integrity Checker** | Monitors directories for file changes using SHA-256 | `ficheck.py` |
